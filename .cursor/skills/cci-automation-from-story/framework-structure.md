# Katalon framework structure (CCI)

Canonical layout for assets generated by **cci-automation-from-story**. Aligns with [co-pilot-automation-skill](../../skills/co-pilot-automation-skill/SKILL.md) and [qa/automation/KATALON-INDEX.md](../../../qa/automation/KATALON-INDEX.md).

## Project root

`KATALON_PROJECT_ROOT` = repository root (where `Corp.microservice.ccm-automation.prj` lives).

## Folder tree (per story)

```text
Test Cases/<MODULE_ROOT>/<STORY_KEY>/TC_<TC_ID>_<slug>.tc
Scripts/<MODULE_ROOT>/<STORY_KEY>/TC_<TC_ID>_<slug>.groovy
Object Repository/<MODULE_ROOT>/<STORY_KEY>/<element>.rs
Keywords/<MODULE_ROOT>/BusinessActions.groovy   # extend existing class when present
Test Suites/CCI_<MODULE_ABBR>_<STORY_KEY>_SUITE.ts
```

## Reuse before create (mandatory order)

1. **Object Repository** — search `Object Repository/<MODULE_ROOT>/` (any story folder) for matching control names.
2. **Keywords** — search `Keywords/<module>/`, `Keywords/ap_ar_management/`, `Keywords/globalsettings/`, etc.
3. **Scripts** — mirror patterns from sibling `Scripts/<MODULE_ROOT>/<other-story>/`.
4. **Profiles** — `Profiles/default.glbl` for URLs (`*_URL`, `GLOBAL_SETTINGS_URL`, …).
5. **FE source** — [fe-be-locator-playbook.md](fe-be-locator-playbook.md) under `.cursor/cci-skills/FE-ApplicationCode/`.
6. **BE source** — same playbook under `.cursor/cci-skills/BE-ApplicationCode/services/` (assertions, error messages, API paths only when UI test needs them).

## Script header (every `.groovy`)

```groovy
// Jira TC: <JIRA_KEY> | Story: <STORY_KEY> | TC_ID: <TC_ID>
// Source: cci-automation-from-story | Module: <MODULE_ROOT>
```

## Encoding

UTF-8 **without BOM** on all `.groovy`, `.tc`, `.rs`, `.ts`.

## Login

Do **not** implement Entra login in feature scripts. Preconditions “logged in as OPS/ADMIN” are satisfied by suite setup or separate login suite — see co-pilot-automation-skill.

## Waits & screenshots

Before each interaction: `waitForElementVisible` + `waitForElementClickable` (30s default).  
`WebUI.takeScreenshot()` after major steps and in `catch` before `markFailedAndStop`.

## Self-healing

Set `smartLocatorEnabled` true on new `.rs` when using CSS/XPath; prefer `aria-label`, stable `id`, or label-based XPath from FE grep.
